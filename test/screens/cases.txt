# 画面の回帰テスト（T-078 / T-114）。`cargo xtask test-screens [--bless] [--no-dist] [名前の一部...]`
#
# embterm.exe（target/dist）を 1 ケースごとに起動し、入力を PTY に送り、画面のテキストを
# test/screens/<名前>.txt（期待値）と比べる。--bless で期待値を書き直す。撮った画面は target/screens/。
#
# 書き方:
#   @グループ 桁 行 最初の入力までの ms 入力の間隔 ms 最後の入力から撮るまでの ms -- コマンド 引数...
#   名前 <TAB> 入力 <TAB> 入力 ...        入力は embterm.exe の --input と同じエスケープ（\r \e \xHH \u{HHHH}）
#   名前 の後に `settle=MS` を置くと、そのケースだけ撮るまでの時間を変える
# 比べるときは行末の空白と、末尾の空の行を除く。

@cmd 60 8 1500 300 1200 -- cmd.exe /d /q /k prompt $g
cmd-echo	echo hello 日本語 ①★※ ─│┌┐\r
cmd-wrap	echo 0123456789012345678901234567890123456789012345678901234567890123456789END\r
cmd-cls	echo before\r	cls\r	echo after\r
