# ADR 0002: 子 HWND を重ねて自前で描く（Emacs のバッファには描かない）

- 日付: 2026-11-11
- ステータス: 採用（要件 [§5.2](../requirements.md) / [§5.6](../requirements.md)、TODO [T-008](../TODO.md)。
  埋め込みの約束は `~/.emacs.d/docs/embed/hwnd-child-window.md`、先例は GenPreview）

## 背景

前身の ghostel は、端末の画面を **Emacs のバッファのテキスト**として描いていた。
これだと表示が Emacs の表示の仕組みに縛られる。

- セルの幅は `char-width-table` が決める。**これは Emacs 全体で 1 つ**なので、
  「端末の中だけ `①` を 1 桁、ほかのバッファでは 2 桁」ができない。
  claude は `①` などの East Asian Ambiguous を 1 桁として描くので、**桁がずれる**。
- グリフの大きさも行の高さに縛られる。`★` `※` は 1 セルに収めるため高さ 47% に縮められていた。
- 画像（Kitty graphics）を出す素直な手段が無い。

一方 GenPreview で「Emacs のフレームに子 HWND を重ね、module が自分で描く」方式が実用になっていた。

## 検討した案

**どこに描くか**

| 案 | 評価 |
|---|---|
| Emacs のバッファのテキストとして描く（ghostel） | 上記のとおり文字幅とグリフが Emacs に縛られる。本題（claude の桁ずれ）が解けない |
| **フレームの HWND を親にした子 HWND に自分で描く** | 文字幅もグリフも自分で決められる。画像も描ける。GenPreview で実績がある |

**何で描くか**（T-008）

| 案 | 評価 |
|---|---|
| **Direct2D / DirectWrite + DXGI のフリップモデル** | GenPreview と共通。フォントのフォールバック・ClearType を OS に任せられる |
| Direct3D + 自前のグリフのアトラス | 速いが手間が大きい。まず D2D で作り、足りなければ移る |

## 決定

**フレームの HWND を親にした `WS_CHILD` のウィンドウを `window-inside-pixel-edges` に合わせて置き、
Direct2D / DirectWrite + DXGI のフリップモデルで描く。**

負荷は T-068 / T-054 で測り、**アトラスには移らなかった**。文字を色ごとに 128 グリフずつまとめ、
背景を「セル 1 つ = 1 画素」のビットマップ 1 枚にすることで、最悪の画面（314x70、セルごとに色が違う）で
80 ms → 6〜8 ms になった。

埋め込みの約束:

- 子 HWND は作ったら `HWND_BOTTOM`、動かすときは `SWP_NOZORDER`（corfu などの子フレームを隠さない）
- `WS_EX_NOACTIVATE` と `MA_NOACTIVATE` でフォーカスを取らない（[ADR 0004](0004-keys-in-emacs.md)）
- バッファが見えなくなったら隠す。クリックされたら、その子 HWND を持つ Emacs のウィンドウを選ばせる
- 子 HWND を持つスレッドで重い処理をしない（入力キューが Emacs と連結する）

## 帰結

- **Emacs のバッファの中身は置き物になる。** `C-s` / `M-w` / occur がそのままでは効かないので、
  copy モード（`C-c C-k`）でスクロールバックごとバッファに写す道を別に用意した（T-017）。
- Emacs のカーソルは子 HWND の下で見えない。カーソルの形・フォーカスの表現・IME の変換中の文字列の位置は、
  すべて端末側で面倒を見ることになった（[ADR 0005](0005-ime.md)、T-133 / T-134 / T-137）。
- 文字幅を自分で決められるので、claude の桁ずれは解けた（[ADR 0006](0006-eaw-width.md)）。
- macOS には子 HWND が無いので、`EmacsView` のレイヤーに `CAMetalLayer` を足す形に置き換えた（T-125 / T-126）。
  レイヤーはマウスの当たり判定に出ないので、Emacs の操作をそのまま残せるという副次的な利点があった。
